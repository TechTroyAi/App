# Batch 13 — bound sigils

Integrated the complete original persistent-imbuement family:

- Might
- Tempo
- Reach
- Clarity
- Echoes
- Conservation

Every bound sigil inherits the physical hexagonal seal, brass rim, and six binding notches established by Batch 12's Blank Sigil. Mechanic-specific inlays distinguish forge strength, cycle speed, operating radius, Hex resistance, repeated activation, and resource efficiency.

The high-resolution `*_source.png` concepts were created specifically for Blockhold Defense. `processed/` contains transparent 64×64 outputs produced by `tools/process_sprite_batch_13.py`.

`bound-sigil-review.png` presents all six imbuements at enlarged nearest-neighbor scale and is not packaged into the APK.
