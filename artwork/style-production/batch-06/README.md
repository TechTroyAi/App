# Batch 06 — complete Utility family

Integrated original gameplay sprites:

- Cache Depot
- Forge Workshop
- Purifier Totem
- Surveyor Station
- Reforge Anchor
- Salvage Yard

Together with the approved Block Generator prototype, these complete all seven non-attacking Utility visuals. They share one stone-and-machinery construction language while retaining distinct functional cues: protected storage, furnace crafting, cleansing rings, survey optics, terrain stabilization, and scrap processing.

The high-resolution `*_source.png` concepts were created specifically for Blockhold Defense. `processed/` contains transparent 64×64 outputs produced by `tools/process_sprite_batch_06.py`.

`utility-family-review.png` presents the complete family at enlarged nearest-neighbor scale and is not packaged into the APK.
