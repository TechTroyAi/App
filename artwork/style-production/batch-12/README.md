# Batch 12 — crafted supplies

Integrated the complete original crafted-supply icon family:

- Core Patch
- Recovery Wrap
- Purifier Vial
- Reforge Coupler
- Utility Gearset
- Survey Lens
- Trap Refit Kit
- Blank Sigil

Each icon uses a distinct physical silhouette suited to compact inventory slots. The Blank Sigil intentionally has an empty recessed face so the six bound imbuements can remain visually distinct from the unbound crafting component.

The high-resolution `*_source.png` concepts were created specifically for Blockhold Defense. `processed/` contains transparent 64×64 outputs produced by `tools/process_sprite_batch_12.py`.

`crafted-supply-review.png` presents all eight supplies at enlarged nearest-neighbor scale and is not packaged into the APK.
