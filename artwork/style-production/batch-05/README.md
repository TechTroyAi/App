# Batch 05 — elite enemies and recurring boss

Integrated original gameplay sprites:

- Blink Stalker
- Rootcaller
- Hex Weaver
- Siege Colossus
- The Overgrowth

Together with the approved Ironhide Champion prototype, these complete all five elite visuals and the recurring boss. Each silhouette exposes its combat role: Blink Stalker is phased and predatory, Rootcaller projects regenerative tendrils, Hex Weaver stretches disabling energy threads, Siege Colossus is built like a moving fortress, and The Overgrowth is the source of corruption.

The high-resolution `*_source.png` concepts were created specifically for Blockhold Defense. `processed/` contains transparent 64×64 outputs produced by `tools/process_sprite_batch_05.py`. The shared processing pipeline removes bright neutral backdrop fragments trapped inside enclosed limb and energy gaps.

`elite-boss-family-review.png` presents the full elite family and boss at enlarged nearest-neighbor scale and is not packaged into the APK.
