# Batch 09 — Ember Forge and Resonance Beacon

Integrated original layered tower sprites:

- Ember Forge pedestal
- Ember Forge animated flame core
- Resonance Beacon pedestal
- Resonance Beacon rotating pulse

These complete the original five-tower base roster. Ember Forge retains its breathing flame-scale animation; Resonance Beacon retains its ambient rotating signal. Both toolbar icons now composite the pedestal and effect rather than showing a detached effect alone.

The high-resolution `*_source.png` concepts were created specifically for Blockhold Defense. `processed/` contains transparent 64×64 layer outputs produced by `tools/process_sprite_batch_09.py`.

`layered-tower-review.png` composites the two completed towers at enlarged nearest-neighbor scale. It is a review image and is not packaged into the APK.
