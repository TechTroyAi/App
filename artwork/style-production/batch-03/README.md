# Batch 03 — complete trap family

Integrated original gameplay sprites:

- Root Snare
- Ember Rune
- Arc Plate
- Crusher Block

Together with the approved Spike Bed prototype, these complete all five trap visuals in the dark industrial forge-fantasy style.

The high-resolution `*_source.png` concepts were created specifically for Blockhold Defense. `processed/` contains the transparent 64×64 outputs produced by `tools/process_sprite_batch_03.py`. The Root Snare requires an additional enclosed-background cleanup because its curled roots surround open negative space.

`trap-family-review.png` presents the complete family at enlarged nearest-neighbor scale.
