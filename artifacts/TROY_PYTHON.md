# Troy Python v2.0.0

Installable APK: `Troy-Python-v2.0.0-installable.apk`

VS Code–style Python interpreter for Android.

- Keyboard does not cover the editor (`adjustResize` + viewport shrink + **hide keyboard** button)
- Pinch or **+ / −** to zoom the code
- Wrap off = wide horizontal scroll like VS Code
- Syntax colors, line numbers, file explorer, snippets, Run / terminal
- Offline Python subset (print, loops, functions, lists, dicts, math, random, classes)

Sideload on Android 7+. If Blockhold Defense is already installed, uninstall it first (same package id `ai.techtroy.blockhold`).
