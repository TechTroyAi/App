# Installable build

`TechTroy-debug.apk` is the compiled, debug-signed starter application.

- Package: `ai.techtroy.app`
- Version: `1.0.0` (`1`)
- Minimum Android: 7.0 / API 24
- Target Android API: 35
- SHA-256: `064638822c597a10616834dedebff93353f348a14bbdae6f230127c605d8cfce`

This is a debug build intended for direct device testing. A production release should be signed with a private release key that is stored outside this repository.
